Push a layer

Each button signs a new manifest and streams it to this host and to every other device with this page open. The host verifies it, runs it once against your real state, and only then swaps it in.

    Edit the code live

    The main layer is AssemblyScript; the progress card is C. Edit the main layer, then compile it right here in the browser and stream it. The first compile downloads the compiler (about 14 MB), so give it a moment.

    The C layer is read-only here; browsers have no C compiler.

    What happens on every push
    
        
    
          
    1 · VerifySignature from a trusted publisher; version newer than the running one.
    
          
    2 · FetchOnly layers whose hash this host doesn't hold; each hash checked.
    
          
    3 · RehearseRun migration and one render on a shadow copy of state.
    
          
    4 · SwapCommit atomically; keep the old layer for instant revert.
